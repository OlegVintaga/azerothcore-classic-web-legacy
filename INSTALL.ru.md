# Установка

[English version](INSTALL.md)

## 1. Требования
- PHP 8.0+ с расширениями `mysqli` и `mbstring`
- MySQL 8.0
- Apache (или nginx + php-fpm) с виртуальным хостом на корень проекта
- Работающий AzerothCore 3.3.5 со стандартными базами `acore_auth` /
  `acore_characters` / `acore_world`

Для установщика нужен пользователь MySQL с правом **создавать базы данных**
(он создаёт базу сайта). После установки самому сайту достаточно прав на чтение
и запись в базу сайта и только чтение в трёх игровых базах.

## 2. Файлы
Разместите весь проект в корне виртуального хоста, например `/var/www/wow`.
Убедитесь, что веб-сервер может писать в:
- `config/` (установщик записывает `config/config-protected.php`)
- `install/` (установщик создаёт `install/DISABLE_INSTALLER.php`)

## 3. Запуск установщика
Откройте в браузере `http://ваш-сайт/install/` и заполните единственную форму:

- доступы MySQL (хост, порт, пользователь, пароль) и имена баз: auth,
  characters, world — плюс база сайта (по умолчанию `site`, создастся, если её нет);
- название сайта, email, имя куки, тип клиента (expansion).

Установщик импортирует SQL в базу сайта (таблицы сайта + справочные таблицы
армори), **сам регистрирует реалмы** — для каждого реалма из `realmlist`
auth-базы (или realm id 1, если `realmlist` пуст) с указанными доступами, —
затем пишет `config/config-protected.php` и создаёт
`install/DISABLE_INSTALLER.php`, который блокирует установщик. Не удаляйте
этот файл: удаление снова включает установщик (это нужно только при чистой
переустановке).

## 4. Администраторы сайта
Группа сайта `Administrators`/`Root Admins` даёт доступ к админ-панели.
Как её получить:

- **Автоматически при входе на сайт** по игровому gmlevel (`account_access`):
  - 1–2 (модератор/GM) → группа **Moderators** (форум и галерея на модерацию,
    без доступа к админ-панели сайта);
  - 3 (админ игры) → **Root Admins** (полная админ-панель сайта);
  - 0 — не трогается; автоматического понижения нет (группы, выданные вручную,
    и бан не перезаписываются).
- Вручную (например, для человека без gmlevel): зарегистрироваться на сайте
  и в базе сайта выполнить
  ```sql
  UPDATE website_accounts SET g_id = 3
  WHERE account_id = (SELECT id FROM <auth-база>.account WHERE username = 'ВАШ_ЛОГИН');
  ```
  `g_id`: 2 = Members, 3 = Administrators, 4 = Root Admins
  (полный список — таблица `website_account_groups`).

После смены группы нужно заново войти на сайт. Отдельного интерфейса для
смены группы сайта в админ-панели пока нет. Группы сайта управляют только
сайтом и не связаны с игровым gmlevel.

## 5. Дополнительные настройки
- **Язык армори и опции** — `armory/configuration/settings.php`
  (`"Lang"` = `en_us`, `de_de`, `fr_fr`, `ru_ru`).
- **Шаблон сайта** — папки в `templates/`, выбор в `config/config.xml`.
- **Справочники армори** (имена подземелий/боссов/зон) ставятся вместе с
  установщиком в базу сайта; имена зон для нерусских языков взяты из DBC клиента
  (`AreaTable.dbc`), русские — из локалей ruRU.

## 6. Обновление сайта
Когда выходит новая версия сайта: замените файлы сайта (не удаляя
`config/config-protected.php`), затем откройте `install/update.php` и
подтвердите обновление паролем MySQL, который сайт использует (он записан
в `config/config-protected.php`). Апдейтер применит все SQL-файлы из
`install/sql/updates/` с номером выше текущей версии схемы (таблица
`website_version`) и зафиксирует новую версию. Перед обновлением сделайте
дамп базы сайта. Формат файлов обновлений описан в `install/sql/updates/README.txt`.

## 7. Переустановка / удаление
- Переустановка: удалить `config/config-protected.php`, удалить
  `install/DISABLE_INSTALLER.php`, удалить базу сайта, запустить установщик заново.
- Игровые базы не изменяются никогда, поэтому удаление базы сайта полностью
  убирает все следы сайта.
