# Веб-обёртка для AzerothCore

[English version](README.md)

PHP-сайт + армори персонажей для серверов [AzerothCore](https://github.com/azerothcore/azerothcore-wotlk)
(WotLK 3.3.5). Работает со стандартной структурой баз AzerothCore 3.3.5; при этом
привязки к конкретному серверу в коде нет — доступы к БД, имена и адреса реалмов,
язык, шаблон задаются при установке или в конфигурационных файлах.

## Возможности
- Установщик в браузере (`/install`) — создаёт базу сайта (имя задаёте вы, по
  умолчанию `site`), записывает `config/config-protected.php`, а после завершения
  закрывает сам себе доступ файлом `install/DISABLE_INSTALLER.php`, чтобы
  установку нельзя было повторить из браузера
- **Армори**: листы персонажей (экипировка, таланты, достижения, репутации, навыки),
  гильдии, арена-команды и рейтинги, страницы существ и предметов, поиск предметов
  с тултипами, просмотр аукциона, рейтинги чести/арены
- **Аккаунты**: регистрация, менеджер аккаунта, отправке GM-тикета
- Языки интерфейса: английский, немецкий, французский, русский
- Доступ к `acore_auth` / `acore_characters` / `acore_world` только на чтение —
  игровые базы не изменяются; все данные сайта хранятся в отдельной базе для сайта
  (её создаёт установщик, имя задаёте вы)

## Требования
- PHP 8.0+ (mysqli, mbstring)
- MySQL 8.0
- **Только AzerothCore 3.3.5** (стандартная структура БД). Тестировалось на
  master, ревизия `b704af465` (04.11.2026). Другие ядра того же периода не подходят:
  например, сверка с TrinityCore 3.3.5 (TDB 335.26091) показала другую схему
  авторизации, талантов, моделей существ и части справочников — сайт под Trinity
  не адаптирован

## Установка
См. [INSTALL.ru.md](INSTALL.ru.md). Кратко: направить виртуальный хост на корень
проекта, открыть `http://ваш-сайт/install/` и пройти мастер установки.

## Структура
- `install/` — установщик + SQL базы сайта (`install/sql/`)
- `armory/` — движок армори (`armory/configuration/settings.php` — язык и опции)
- `core/`, `templates/` — каркас сайта и шаблоны
- `config/` — конфигурация сайта (создаётся установщиком)
