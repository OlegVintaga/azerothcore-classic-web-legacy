Обновления базы сайта
=====================

Формат имени файла: ЧИСЛО_краткое_имя.sql, например:

    0002_add_donation_table.sql
    0003_items_locale.sql

ЧИСЛО — номер новой версии схемы. Правила:

* Каждое обновление выкладываете ВЫ (в релиз сайта), пользователь просто
  открывает install/update.php (или php install/update.php --yes).
* Применяются все файлы с номером больше текущего значения таблицы
  website_version.version; каждый файл — ровно один раз.
* Файлы обновлений не удалять и не переименовывать: по номеру определяется,
  что уже применено. Старые файлы спокойно лежат в релизе вечно.
* Один запрос = несколько строк, конец запроса — точка с запятой в конце
  строки (как в дампах установщика). Внутри запроса «;» в конце строки
  быть не должно.
* Строки, начинающиеся с «-- », — комментарии, игнорируются.
* Плейсхолдер {{AUTH_DB}} заменяется на имя auth-базы из конфига сайта
  (для обновлений, трогающих представления realmlist/uptime/account_access).
* Обновление — это DDL: на неудачном файле процесс останавливается,
  ранее применённые файлы остаются зафиксированными. Перед обновлением
  базы сделайте дамп (mysqldump).

Начальная версия схемы (ставится установщиком): 1.

Шаблон:

    -- 0004_example: добавляет таблицу примера
    DROP TABLE IF EXISTS `website_example`;
    CREATE TABLE `website_example` (
      `id` int NOT NULL AUTO_INCREMENT,
      PRIMARY KEY (`id`)
    ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
